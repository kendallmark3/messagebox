# Idea templates

Templates for submitting an idea to the Ideas Workbench without typing everything at each stage.

| File | What it is |
| --- | --- |
| [idea-template.txt](idea-template.txt) | The blank template. Replace each `[bracketed prompt]` with your own words and delete any section you can't fill in yet. |
| [example-idea.txt](example-idea.txt) | A filled-in example, ready to paste into **Submit Idea** to see what happens. It is an illustration, not a real idea. |
| [intents/](intents/) | The intent files the app was built from, V1 to V5. |

## How to use one

1. Open the file and copy all of it.
2. Paste it into **What's your idea or problem?** on the Submit Idea screen.
3. Submit.

Only **Problem** is needed to submit. Each later section matches a stage in the pipeline:

| Section | Used when the idea moves |
| --- | --- |
| Evidence | Problem → Evidence |
| Why it is worth prototyping | Evidence → Prototype |
| Prototype | Prototype → Pilot |
| Pilot | Pilot → Investment |
| Outcome, Hours saved per week | When an outcome is recorded at Pilot or Investment |

## What the workbench does with it

Today the whole text is evaluated as one suggestion, and stage notes are still typed by hand. [intentv4.md](intents/intentv4.md) describes the change that makes the workbench recognise the sections and reuse them at each stage.

Keep the section names and the colon exactly as written, each on its own line, so the workbench can find them. A submission can be at most 4,000 characters.
