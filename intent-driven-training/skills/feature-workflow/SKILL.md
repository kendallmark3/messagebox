# Feature Workflow

Use the smallest useful loop:

**Intent -> smallest safe delta -> validation -> evidence -> refine only when evidence says so**

Keep the intent focused on:
- Inputs
- Outputs
- Success criteria
- Constraints / boundaries

Do not prescribe implementation unless it is genuinely required. Prefer progressive intent: begin lean, run, inspect evidence, and add only what the evidence proves is missing.
